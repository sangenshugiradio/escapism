# ESCAPISM 現現現

今の気持ちと、目の前の景色の写真から、その瞬間だけのアンビエントを生むWebサービスです。
音はすべてブラウザの中でリアルタイムに合成します。ログインは要りません。

**サイト:** https://sangenshugiradio.github.io/escapism/

## 使い方

1. 上の枠に、目の前の景色の写真を入れる
2. 今の気持ち、頭から離れないことを書く
3. 「手放す」を押す — 淡い光が広がってから、曲が流れはじめます

- AMBIENT / BEAT でビートの有無を選べます（再生中に切り替えると、いまの曲がそのまま変わります）
- 空いているところをタップすると音が鳴り、ダブルタップでグリッチ、長押しで音が引き、写真をなぞるとフィルターとエコー、上下にはじくと転調します
- 「動画で保存」で、いまの曲と画面を15秒の横長動画にできます（iPhoneでは共有シートから「ビデオを保存」、パソコンではダウンロード）
- 入力した悩みは、数秒で文字がほどけて消えます
- 曲ごとに最初に鳴る楽器が変わります（グランドピアノ／リズムを刻む電子音／環境音だけの導入／シンセ／ディレイのギター／ドローン）。気持ちと写真の色から選び、同じ始まり方は続きません。「ピアノ」「雨」「テクノ」など、楽器や場所を書くとそれが選ばれやすくなります
- 曲が流れはじめると、ページの下に、そのときの気持ちに合いそうな映画・小説・マンガ・随筆がランダムに3つ出ます（「Shuffle」で選び直せます）
- ページの一番下から、三現主義ラジオ（YouTube・Spotify・Apple Podcasts）へ飛べます

## 構成

| パス | 内容 |
|---|---|
| `src/page.html` | ページ本体（音のエンジン、デザイン、解析） |
| `docs/sangenshugi-radio.jpg` | 三現主義ラジオのアートワーク（WordPress 版もこのURLを参照） |
| `docs/index.html` | 単体で開けるHTML（GitHub Pages など）。`python3 tools/build.py` で `src/page.html` から生成 |
| `wordpress/escapism-wordpress.html` | WordPress のカスタムHTMLブロック用 |

## WordPress で使う

`wordpress/escapism-wordpress.html` の中身を、投稿や固定ページの「カスタムHTML」ブロックにそのまま貼り付けます（`python3 tools/build_wp.py` で `src/page.html` から生成）。

- CSS はすべて `#escapism` の中だけに効き、要素の id には `esc-` が付き、スクリプトは関数の中で動くので、テーマや他のプラグインとぶつかりません。
- 貼り付けには「unfiltered_html」の権限（管理者）が必要です。

## しくみ

- サーバーもAIも使いません。写真の色・明るさと、書いた言葉のキーワードから、端末の中でジャンル・編成・調・環境音・曲名・流れる文章を組み立てます。
- 書いた言葉と写真はどこにも送られず、保存もされません。
- 音はすべて Web Audio API でリアルタイムに合成しています（5-limit 純正律、Eno 式の割り切れない周期のループ、グラニュラー、テープ、畳み込みリバーブ、合成した環境音、16ステップのビート）。
